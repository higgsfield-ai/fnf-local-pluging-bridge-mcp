# Reuse and Updates

## Verified unchanged repeat

A repeat creates a separate import. Reuse only an unchanged source with a previously verified native dependency tree, durable media and a complete identity map. Check current source identity and content fingerprints against the recorded source, child order, media, timing and hierarchy policy. Confirm that the saved native content has not changed since verification. A cache file's existence alone is insufficient.

Use a supported non-destructive import or duplicate the verified dependency tree while preserving intended sharing within the new import. Never open a cached project over the user's project. Validate imported media paths and rebind the map to new composition and layer identities. Copying footage files does not relink them automatically.

Validate already cropped dimensions without recropping. Compare a native preview against the previously verified preview under matching conditions, then perform the shared dependency audit. A cached preview comparison proves consistency with that preview, not independent equivalence to Figma. Report any comparison tolerance used.

On a source, metadata, dependency or verification mismatch, take the fresh route with the original timer. Reserve enough remaining time for mutation, verification and safe completion; do not start a cached import with fewer than 15 seconds left in the total budget. Creating a reusable standalone project requires an explicit request and a supported export that preserves the open project; otherwise report that cache creation is unavailable.

## Explicit mapped update

An update requires the requested destination and a map connecting source identities to actual native items. Match by identity rather than display name. If the map is missing or ambiguous, resolve the target before mutation; do not silently replace the import.

Read the source and native-layer references for changed content, and the geometry reference when transforms or hierarchy change. Capture fresh source state and compare geometry, text, styles, media, visibility and child order with the mapped version. Identify properties animated or edited in the destination. Update only the requested scope, preserving unrelated animation and user edits; ask only when a source change conflicts with them and the request does not resolve precedence.

Before structural replacement, preserve an independent recoverable copy of the affected native dependency tree using a supported project operation. A disappeared source node does not authorize deleting an animated layer. Do not recrop an animated composition with static crop compensation. If the necessary identity or animation-preserving operation is unavailable, report the affected nodes and stop dependent changes.

Reconcile stacking and matte dependencies after changes, verify affected appearance within the complete frame and audit the resulting graph. Update source fingerprints, destination identities and verification state only for successfully completed changes; retain explicit partial status for unresolved nodes.
