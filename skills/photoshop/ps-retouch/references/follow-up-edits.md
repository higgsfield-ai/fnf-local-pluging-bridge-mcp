# Source for another editing round

For another edit of the same photograph, honor an already applicable source preference, including an explicitly named earlier version. Otherwise ask once whether to redo the edit from the original or edit the specific current result. Recommend the original to reduce accumulated generation loss, without treating that recommendation as an answer. Identify the photograph and current result with labeled previews or thumbnails.

Use a visible native clickable choice when available. Otherwise use the installed visualization skill's documented interaction if available, or ask the same concise question in chat. Localize the question, explanation and controls. A source choice may submit directly and does not require another profile-and-wishes form. Wait for an explicit answer.

Keep the selected profile, adaptation mode and all applicable wishes. From the original, assemble one coherent prompt containing accepted edits and new corrections, excluding rejected or superseded changes. From a prior result, use that exact image, preserve its accepted finish and apply the requested correction within scope. Never substitute the latest output for a specifically selected version.

This decision is for a new editing round, not for an initial edit, prompt discussion, skill revision or already-running generation. Requests collected before one generation belong in that pass. Recovery after a failed generation retains the selected source and does not reopen this choice. The resulting comparison uses the actual input for this round.
