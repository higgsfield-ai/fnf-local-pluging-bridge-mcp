# Native Puppet

## Mesh creation and proof

Read this reference only for soft parts requiring Puppet. Complete separation, hidden reconstruction and overlap testing first. Create a mesh on each appropriate prepared alpha rather than one flattened character with hair, face and decorations glued together. Place a small set of meaningful anchors at roots, bend regions and moving tips; pin count follows the part's geometry.

Discover an available native pin-creation operation. If the interface must be used, read the actual application state, frame, zoom and layer transforms, calibrate one pin and inspect its resulting native position before placing more. Follow the active interface tool's permissions; authorization for a different input mechanism belongs to the current session, not to this skill. The agent performs placement and verification instead of silently assigning it to the user.

In the verified application version, the pin tool enum is `ToolType.Tool_Pin`. Native existing pins were exposed beneath effect `ADBE FreePin3`, then `ADBE FreePin3 ARAP Group`, `ADBE FreePin3 Mesh Group`, the selected mesh, `ADBE FreePin3 PosPins`, the selected pin and `ADBE FreePin3 PosPin Position`. Inspect the current tree and associate pins with their coordinates and role; indices can change when properties are added. An empty property created by `addProperty` does not prove a functioning mesh.

Demonstrate deformation with the layer transform held fixed: render rest, move one native pin, render again and verify that the intended part deformed, then restore it. Bind controls only after this proof. Keep roots stable and add restrained delayed motion to flexible tips. Retest intermediate poses because a deformed edge can reveal pixels missed by rigid overlap tests.

## Recovery

Save after verified small groups of mesh edits. If the application crashes, recover the latest saved checkpoint and isolate the failing operation on one part. Do not repeat a batch that has already produced the same crash. If native pin creation remains unavailable or unsafe to repeat, preserve the prepared layers and report the exact unfinished capability. An alternative deformation method may be appropriate if the user permits it, but must not be labeled a completed Puppet rig. Recheck or rebuild meshes when the underlying alpha changes.
