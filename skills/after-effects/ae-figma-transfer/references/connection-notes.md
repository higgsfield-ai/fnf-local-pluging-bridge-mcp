# Connection Behavior

Inspect the selected connection's current schemas and required application guidance before mutation. Operation names, batch envelopes, host paths and payload limits belong to that connection; do not infer them from another provider's interface. A connection must expose usable source data and native destination operations before the transfer can be described as executable.

For native project import, verify additive behavior and preservation of the open project. Check whether repeated shape property types remain distinct. If the importer merges them, use supported native content operations that preserve the complete ordered stack and verify the result. Do not assume successful structured import proves complete geometry.

Read back text origin, tracking and range styling when the connection normalizes them. Check gradient endpoint coordinates against actual layer transforms. Confirm that inner shadows, group blur and layer styles use the intended native compositing behavior rather than a similarly named effect. Enable a required style through the supported application operation before assigning its properties.

Handle only behavior relevant to the selected connection and observed source features. An SVG or PDF import may be useful transport but does not itself establish native editability. Retry a preview after settling only when stale rendering is observed; unresolved differences remain verification failures.
