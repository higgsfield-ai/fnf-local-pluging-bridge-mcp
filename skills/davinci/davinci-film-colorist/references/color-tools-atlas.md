# Selecting a Color Tool

Choose a tool according to the dimension that needs changing. Broad tonal relationships call for appropriate primary controls; a confined signal range can call for Log, HDR, or curves. A tonal range is not a semantic or spatial object. Use a verified selection when the subject cannot be distinguished by signal value alone.

Separate hue rotation, saturation, density, and luminance adjustments. A color appearing weak can reflect a tonal problem, a wrong hue, or low chroma. Establish the cause before moving multiple controls. Warper and ColorSlice provide different selection and correction mechanisms and do not guarantee protected skin.

Distinguish image processing from key processing and geometry. A matte-cleaning Denoise control does not clean RGB noise. A depth estimate does not provide surface normals. A Window track, an effect's analysis region, a semantic mask, and a keyframe curve have different meaning and temporal behavior.

Select Serial, Parallel, Layer, channel splitting, or Key Mixer according to dependency, composition, channel processing, or matte combination. Inspect real connections and graph scope. A similarly named control in a timeline compositing API does not necessarily control a Color Layer Mixer.

When a needed control is not visible, inspect the current palette mode and actual capability schema. Broad tool-family coverage is not evidence of one specific setter. Verify access and a bounded operation, and consult the relevant detailed reference from the entrypoint only when that decision requires it.
