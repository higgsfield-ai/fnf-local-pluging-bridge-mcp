# Effect Execution Contracts

Before adding or replacing an effect, establish the intended node, current contents, input and output domain, required alpha or auxiliary RGB, host compatibility, and available return state. An effect added to an occupied node can replace or interact with existing processing; inspect the current host behavior and keep distinct tasks separate when ordering matters.

Read the effect's own color-management controls. Project management does not guarantee that every effect infers the desired domain, and explicit conversion can duplicate automatic handling. Distinguish built-in color correction from an assigned technical LUT, a creative LUT, and a spatial or temporal effect.

Preserve the real parameter state before testing. Test an effect with an actual compatible image and establish its source isolation or diagnostic view before adjusting overall strength. Verify the selected effect, its enabled state, connections, and fresh native output. Return diagnostic modes to their ordinary state before judging the complete grade.

DCTL rebuild, UI reset, and LUT-list refresh are different actions. Historical documentation uses conflicting Reload and reset terminology. Inspect the installed SDK and actual interface, preserve the code revision and custom controls, and verify whether a rebuild retained them. Do not substitute a grade reset for a file reload.

For a technical transform, verify both gamut and gamma at each end and examine mapping independently. For a multi-input effect, an apparent standalone node label does not prove its ports or data types. For alpha, confirm source generation, key transport, and compositing use separately.

An accepted parameter value, visible static response, stable motion, and recoverable result are separate claims. Retain unavailable or unverified aspects explicitly. Use the current official manual through the installed application's Help or the official support channel when behavior is uncertain; do not turn a historical page number or video title into proof of the current tool.
