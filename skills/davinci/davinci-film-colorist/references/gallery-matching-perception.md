# Gallery and Grade Transfer

## Frame and grade identity

Read Still Properties for source clip and source and record timecodes. Match Reference Wipe Frame locates the corresponding frame; it does not restore its grade. Verify the type of each timecode display rather than identifying it by screen position.

A still image and the processing stored in its grade are different evidence. A grouped image can show the combined processing while the saved grade depends on the selected Node Editor scope. Record capture scope and target scope, effective signal chain, and grade version before applying DRX. A correct PNG does not establish that every visible transform is included in the DRX.

Gallery Live Preview applies a still's grade to the current clip and depends on selection. Hover Scrub Preview can also change preview time. Disable unintended previews for ordinary A/B and separately verify Image Wipe state, overlay selection, and visible split. Restoring one checkbox does not guarantee the original Viewer mode.

## Animation and transfer

Read Apply Grades Using, the transfer component selection, source timing, and graph scope before transferring animation. No Keyframes, alignment by source timecode, and alignment by start frame have different behavior; nonoverlapping source ranges can change the effective alignment. Inspect actual keys and images before, between, and after them. A stationary playhead does not establish a static grade.

A newly added version can inherit animation and tracking. Copying only the first mark does not necessarily remove tracking. Use an actually static baseline across the entire processing chain for pixel comparisons or perception experiments.

Transfer a correction only between equivalent signal domains and processing positions. Shared and Group processing remain shared; a local clip version does not isolate them. Inspect Post Group Node Stack Layer where relevant because the last Clip stack can occur after Group Post processing. Keep individual light drift corrections on the intended clip and verify interpolation, motion, and the cut.

## Export and perception

Record whether still export includes a display LUT. Compare native decoded image values only under the same dimensions, encoding, and color interpretation. Export success, image correspondence, grade content, and temporal behavior are separate results.

When testing the influence of surroundings, first establish whether the subject's pixels actually remain unchanged while the background changes. Keep any observer's reported appearance change separate from that pixel comparison. An agent's image analysis does not substitute for a human response in a perception experiment. PNG values do not measure the light emitted by a monitor.

Viewing history can also affect an impression. Compare an unchanged target frame under the relevant viewing sequences without inventing a universal adaptation duration. A changed impression supports a contextual hypothesis but does not prove one physiological cause or identical pixels without measurement.
