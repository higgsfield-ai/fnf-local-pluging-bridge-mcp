# Media creation and packaging

Use existing approved assets first. If new photographic imagery or footage is requested, use an available generation provider or supplied files at adequate resolution. The local AE MCP does not generate images/video, download cloud results, or authenticate to Higgsfield. Discover a separate provider's current capabilities when that workflow is explicitly needed; do not assume fixed model names or silently substitute them.

Keep text, UI, diagrams and simple graphics native. Import real local media paths through cataloged operations, verify duration, dimensions, alpha and frame rate, and package dependencies with the project when requested. Missing files and expired cloud links are not portable project dependencies. Do not regenerate approved media during unrelated edits.
