# Archived FNF bridge skills

Active skills are maintained only in [`../skills/`](../skills/), which is also the runtime corpus. This directory retains `archive/bridge-ae/`, original source provenance and migration notes. The archive is never served or installed and is excluded from the runtime package. No license to redistribute the archived source is assumed; keep this repository private until ownership and licensing are settled.

From the repository root, use `python3 scripts/install-skill.py` to install the entry skill, `npm run skills:manifest` after editing active skills, and `npm run skills:check` to validate the manifest, reference links and archived provenance.

See [migration notes](MIGRATION.md) and [source provenance](provenance.json).
