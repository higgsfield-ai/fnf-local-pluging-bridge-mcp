# Read-only skill evaluation

`skills.xml` contains ten independent discovery and reasoning questions for the pinned local corpus. Use only skill lookup, tool discovery and operation catalog calls. The camera question assumes the default category policy. Do not mutate AE or enable eval to answer these questions.

Expected answers were checked against the bundled guidance and native catalog. These are prepared evaluation cases, not a claim that an independent model evaluation has been run. The automated suite separately tests actual stdio lookup, unknown arguments, read-only availability, corpus integrity and packaging.
