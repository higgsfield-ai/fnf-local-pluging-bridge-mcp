# Live Construction

Work in the user's visible Blender session when showing progress or supporting a screen recording. Establish a readable viewport before construction. Keep the scene visible while using native tools through the available interface or connection; do not replace visible work with an unseen background build.

Make coherent changes in successive passes for the room, major furniture, actors, poses, and final camera composition. Let Blender redraw after each pass so the user can follow what changed. Give brief updates tied to the visible result. Do not repeatedly change workspaces or leave consoles covering the scene.

Use floor or perspective views when they explain placement, then return to the scene camera. During animation work, show the affected interval through playback after a meaningful change. Never present saved snapshots as evidence of a live update when the open Blender scene has not changed.
