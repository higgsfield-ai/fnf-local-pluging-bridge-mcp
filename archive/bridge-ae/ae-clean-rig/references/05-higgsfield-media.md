# Higgsfield media creation and packaging

## This user’s generated media pipeline

For AE motion projects, create required photographic footage and still images through Higgsfield: **Seedance 2.5 at 1080p for video**, **Nano Banana Pro at 2K for still images**. These are this user’s defaults for future media creation, not permission to regenerate already approved media during an unrelated correction. Keep clean authentic logos when appropriate. Text, buttons, prompt windows, diagrams, construction lines, and simple graphics remain native editable AE components.

Before submitting, verify the exact requested model and resolution in the connected Higgsfield catalog. Do not silently replace the model, provider, resolution, or video with a still if that configuration is unavailable; report the unavailable setting and resolve the alternative with the user while continuing independent AE work. Use the connected Higgsfield tools and their current media-input workflow.

Describe each needed media shot from the reference: framing, subject, composition, light, camera movement, subject movement, duration, and entry/exit poses. Generate a clean media plate with no baked-in UI, logos, or typography that belongs in AE. For moving footage, preserve the observed motion; a generated still with invented pan/zoom is not an equivalent substitute. Review the entire returned clip for unwanted motion and temporal defects. Verify the actual downloaded dimensions and duration rather than treating a prompt’s resolution wording as proof.

Import approved results into named replaceable media precomps, with editable text and graphic overlays above them. Package the downloaded originals and record the actual provider, model, settings, and generation/source identifiers. A generator’s scene content is rasterized; keep that limitation clear and make ordinary media replacement practical.

## Explicit model choices override defaults

When the current task explicitly asks for Soul 2.0 at 2K, use that requested configuration instead of the still-image default. Soul 2.0 at 2K was used successfully for the gallery content. This is an example of an explicit override, not a replacement of the user's Nano Banana Pro default. Check live availability and actual dimensions each time: a portrait output may have different pixel dimensions from a square output with the same marketed resolution tier.

Choose framing and aspect ratio for the actual placeholder. Keep faces, subjects and important details within the intended Cover crop; review the asset inside the animated card before accepting it. Preserve an approved card's text, round corners, shading and timing when replacing only its image.

A portable project should include a media manifest with the local relative filename, purpose/card/shot, actual provider and model, requested configuration, returned dimensions and duration, generation identifier if available, and source information. Never put credentials, access tokens or expiring signed download URLs into the manifest. Keep source font names and applicable redistribution terms separate from generated imagery.
